Your app has been created! Follow these steps to deploy.

Domain: {{ domain }}

1

Install the Drown CLI

If you haven't already installed the CLI tool:

pip install drown
2

Log in to Drown

Authenticate with your account (sets up SSH keys automatically):

drown login
3

Initialize your project

If your project isn't already a Git repository:

cd your-project/
git init
4

Connect this app

Link your local repository to this app:

drown create {{ app_name }}

Note: Since you created this app via the web dashboard, this command will link your local Git repository to the existing app rather than creating a new one. It's safe to run even though the app already exists.

5

Deploy your code

Push your code to deploy (uses your main branch):

git add .
git commit -m "Initial commit"
git push platform main

Your app will be built and deployed automatically. Check the build logs in your terminal.

✅ What's next?

  • After pushing, your app will be live at {{ domain }}
  • View logs: drown logs {{ app_name }}
  • Scale replicas: drown scale {{ app_name }} 3
  • Having trouble? Check the troubleshooting guide
