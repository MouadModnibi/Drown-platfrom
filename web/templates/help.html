Help & Troubleshooting

Common deployment issues and their solutions

❌ Application failed health check

Your app deployed but isn't responding to requests

Common causes:

  • App not binding to port 8080
  • App binding to 127.0.0.1 instead of 0.0.0.0
  • Using development server instead of production server

Node.js / React / Vite apps:

Buildpacks can't auto-detect how to serve built frontend apps. You need to explicitly configure a production server:

1. Install the serve package:

npm install serve --save

2. Add to package.json scripts:

{
  "scripts": {
    "start": "serve -s dist -l 8080",
    "heroku-postbuild": "npm run build"
  }
}

Note: Use dist for Vite, or build for Create React App

Python / Flask apps:

1. Add dependencies to requirements.txt:

Flask==3.0.0
gunicorn==21.2.0

2. Create a Procfile:

web: gunicorn app:app --bind 0.0.0.0:8080

Replace app:app with your_file:your_flask_instance if different

🔑 Permission denied (publickey)

Can't push to git remote - SSH authentication failed

Solution:

Run (or re-run) the login command to set up SSH keys:

drown login

This command automatically generates SSH keys and registers them with the platform. If you logged in before the SSH auto-config feature existed, just run it again to update your setup.

🌿 src refspec main does not match any

Git can't find the branch you're trying to push

Cause:

Your repository might be using master instead of main (or a different branch name).

Solution:

Check your actual branch name:

git branch

Then push with the correct branch name:

git push platform master
# or
git push platform your-branch-name

💾 Corrupted or garbled files after push (Windows)

Files contain unexpected characters or fail to parse

Cause:

Using PowerShell's echo "text" >> file or similar commands can inject null bytes or BOM (Byte Order Mark) characters on Windows, which breaks code files.

Solution:

Always use a proper text editor (VS Code, Notepad++, etc.) to create and edit files. If you must use PowerShell commands:

# Use Set-Content with ASCII encoding
Set-Content -Path file.txt -Value "text" -Encoding ASCII

# Or use Out-File
"text" | Out-File -FilePath file.txt -Encoding ASCII

⚠️ Build failed

Your app failed to build during deployment

Troubleshooting steps:

  • Check the build logs in your terminal for specific error messages
  • Verify all dependencies are listed (package.json, requirements.txt, etc.)
  • Make sure your local build works: npm run build or pip install -r requirements.txt
  • Check that you're using compatible versions (Node 18+, Python 3.10+, etc.)

📚 Additional Resources

  • View logs in real-time: drown logs your-app-name
  • Check all your apps: drown apps
  • View resource usage: drown metrics your-app-name
